# Long Story Short

Professional link shortener dashboard built with React, JSX, Vite, Firebase Authentication, and a responsive light/dark interface.

## Features

- Google sign-in with Firebase Authentication
- Email/password sign-up and sign-in
- Firebase configuration through environment variables
- Light and dark theme with local persistence
- Responsive analytics dashboard interface
- Short-link creation flow in the dashboard UI
- Vite development and production build setup
